# Sistem Undangan Elmyra Digital

- `template/` adalah master undangan.
- `samba-mutia/` adalah contoh undangan.
- Untuk pelanggan baru: salin folder template, ubah nama folder menjadi slug pelanggan, lalu edit objek `CONFIG`.
- Nama tamu personal: tambahkan `?to=Nama+Tamu` pada URL.
- RSVP versi ini tersimpan lokal di browser. Tahap berikutnya dapat disambungkan ke database agar ucapan tampil untuk semua tamu.
